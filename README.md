# java-lotto-precourse

## view
### input
- 로또 구입 금액 입력
- 당첨 번호 입력(쉼표로 분리)
- 보너스 번호 입력

### output
- 발행한 로또 수량 및 번호
- 로또 번호는 오름차순
- 당첨 내역 출력
- 수익률 출력
- 소수점 둘째 자리에서 반올림

domain
### 로또
- 번호 리스트
- 오름차순 정렬

### 로또 일급 컬렉션
- 로또 리스트

### 당첨 결과 enum
- 1등 6개 일치, 2000000000원
- 2등 5개 일치 + 보너스 번호 일치, 30000000원
- 3등 5개 일치, 1500000
- 4등 4개 일치, 50000원
- 5등 3개 일치, 5000원

### 당첨 결과 계산
- 당첨 결과 계산
  - 당첨로또, 보너스번호, 발행로또리스트 주면
  - 발행로또리스트 돌면서 당첨로또랑 몇개 맞는지 확인
  - 보너스번호 포함인지 확인
  - 몇등인지 반환
- 수익률 계산
  - 총상금, 구입금액 주면 수익률 반환

### 당첨 통계
- enum 맵
- 총상금

util
### 랜덤 번호 생성
- 1~45 사이 랜덤 번호 6개 생성

### 예외처리
**1. 로또 금액 입력 오류**
- null
- 숫자가 아님
- 1000원 미만
- 1000원으로 나누어떨어지지 않음
  - "[ERROR] 올바른 금액을 입력해 주세요."

**2. 당첨 번호 입력 오류**
- null
  - "[ERROR] 올바른 번호를 입력해 주세요."
- 숫자가 아님
  - "[ERROR] 숫자가 아닙니다."
- 1~45 범위 벗어남
  - "[ERROR] 범위를 벗어난 번호가 포함됐습니다. 다시 입력해 주세요."
- 중복 번호 존재
  - "[ERROR] 당첨 번호는 중복될 수 없습니다. 다시 입력해 주세요."

**3. 보너스 번호 입력 오류**
- null
  - "[ERROR] 올바른 번호를 입력해 주세요."
- 숫자가 아님
  - "[ERROR] 숫자가 아닙니다."
- 1~45 범위 벗어남
  - "[ERROR] 범위를 벗어났습니다. 다시 입력해 주세요."
- 당첨 번호와 중복
   "[ERROR] 보너스 번호는 당첨 번호와 중복될 수 없습니다. 다시 입력해 주세요."





흐름
- 구입 금액 입력
- (구입 금액/1000)개 랜덤 로또 생성
- 로또 일급컬렉션 생성
- 발행한 로또 전부 출력
- 당첨 번호 입력
- 당첨 로또 생성
- 보너스 번호 입력
- 당첨 통계 생성
- 당첨 로또랑 발행한 로또 하나씩 비교하면서 당첨 통계 계산
- 구입 금액이랑 당첨 통계로 수익률 계산
- 당첨 통계 출력
  - 0개도 출력, 수익률 출력
