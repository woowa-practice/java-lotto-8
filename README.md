# java-lotto-precourse

### 0. 제약사항
- 로또 숫자 범위는 1~45
- 1개 로또를 발행할 때 중복되지 않는 숫자 6개 발행
- 로또 1장은 1,000원

### 1. 입력
- 로또 구입 금액
  - 1,000원 단위
- 당첨 번호 입력
  - 쉼표를 기준으로 구분
- 보너스 번호 입력

### 2. 출력
- 발행할 로또 수량 및 번호 출력
  - { }개를 구매했습니다.
  - [번호, 번호, 번호, ...]
- 당첨 내역 출력
  - 3개 일치 (5,000원) - n개
  - 4개 일치 (50,000원) - n개
  - 5개 일치 (1,500,000원) - n개
  - 5개 일치, 보너스 볼 일치 (30,000,000원) - n개
  - 6개 일치, (2,000,000,000원) - n개
- 수익률 출력
  - 총 수익률은 ?%입니다.

### 3. 필요 로직
- 로또 번호 발행
  - 중복되지 않는 1~45 범위의 6개 숫자
- 당첨 확인
  - 당첨 번호와 발행한 로또 번호 비교
  - 당첨 정보 참고하여 최종 당첨 정보 반환
- 수익률 계산
  - 당첨 내역으로 얻은 금액과 구입 금액 비교하여 수익률 반환

### 4. 로또 객체
- 로또 번호

### 5. 로또 일급 컬렉션
- 로또들

### 6. 당첨 정보
- enum
